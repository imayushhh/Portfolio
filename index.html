Azure E-Commerce Data Pipeline

End-to-end Medallion pipeline on Azure that turns raw e-commerce data into analytics-ready tables.

Problem, build & result
Problem
Raw e-commerce data from HTTP and SQL sources needed to be cleaned and modeled before it could be analyzed.
What I built
A Bronze → Silver → Gold pipeline: ingestion with Azure Data Factory into ADLS Gen2, cleaning and enrichment with PySpark on Databricks, and serving through Azure Synapse Serverless SQL (OPENROWSET).
Result
A curated Gold layer that BI tools can query directly from Synapse.
